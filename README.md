# Blinkit-App

## Project Overview

Power BI dashboard project developed for Blinkit sales and operations analysis. The report provides insights into revenue, order trends, product category performance, customer behavior, and operational KPIs using interactive visualizations, DAX measures, and dynamic filtering.

---

## Key Features

* Interactive Power BI dashboards
* KPI cards for Total Sales, Average Sales, Ratings, and Number of Items
* Dynamic slicers and filters
* Drill-through and visual interactions
* Category-wise and outlet-wise sales analysis
* Outlet establishment trend analysis
* Performance optimization using DAX measures

---

## Tools & Technologies

* Power BI Desktop
* Power Query
* DAX
* SQL

---

## Dashboard Insights

* Total Sales Analysis
* Outlet Type Performance
* Item Type Distribution
* Fat Content Analysis
* Outlet Size & Location Analysis
* Ratings & Average Sales Tracking
